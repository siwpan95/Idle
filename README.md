# Idle Clicker — Canvas 放置挂机

一个用 Python tkinter 构建的放置/点击类游戏。融合了**纪元进阶、科技树、英雄系统、装备掉落、主动技能、转生挑战**等系统，35 种装备从石器时代一路发展到太空时代。灵感来源于《兽人领地》《极简塔防》和《巴尔的遗产》。

## 快速开始

```bash
python main.py
```

零外部依赖，纯 Python 标准库。存档自动保存在 `idle_save.json`。

## 游戏系统

### 1. 纪元系统（阶段性目标）
- **6 个纪元**：石器 → 青铜 → 铁器 → 工业 → 数字 → 太空
- 累计收益达标后自动进阶，解锁新装备和技能
- 每个纪元提供全局 DPS 和点击力加成
- 顶部进度条实时显示当前纪元与下一纪元距离

### 2. 装备分类标签
- 5 种分类：**点击 / 产出 / 乘数 / 协同 / 功能**
- 商店按钮左侧色条标识分类，可点击顶部标签筛选
- 分类颜色：红（点击）蓝（产出）橙（乘数）紫（协同）绿（功能）

### 3. 英雄系统（巴尔的遗产灵感）
- **4 位英雄**：🧙 法师、🛡️ 圣骑士、🏹 游侠、⚔️ 狂战士
- 招募英雄花费金币，升级提升被动能力
- **被动加成**：
  - 法师：DPS +10%/级 | 圣骑士：点击力 +20%/级
  - 游侠：DPS +25%/级 + 暴击 10% | 狂战士：DPS +15%/级 + 点击力 +30%/级
- 英雄可装备掉落物品，获得额外属性加成

### 4. 装备掉落系统
- 5 种稀有度：**普通 / 魔法 / 传说 / 神话 / 不朽**
- 闲置过程中随机掉落，稀有度越高掉率越低
- 装备名按稀有度着色（灰/蓝/橙/紫/红）
- 可在转生菜单 → 装备英雄界面中给英雄穿戴

### 5. 主动技能
- 5 种技能，随纪元解锁：
  - 💰 **金币雨**：立刻获得 30 秒 DPS（石器）
  - ⏰ **时间加速**：DPS x3 持续 10 秒（青铜）
  - ⚡ **暴击连击**：下 10 次点击 x50（铁器）
  - 🤖 **自动连点**：每秒 5 次点击持续 15 秒（工业）
  - 🌟 **黄金风暴**：点击力 x1024 + DPS x5 持续 12 秒（数字）
- 各有独立冷却时间，声望升级可缩减冷却

### 6. 科技树（前置条件）
- 部分装备需要先购买其他装备达到指定等级
- 例如：click_booster 需要 clicker Lv.3，orcish_pride 需要 goblin Lv.1
- 不满足条件的装备显示锁定状态和纪元标签

### 7. 转生与挑战
- **转生**：重置进度，获得声望点数（公式：∛总收益）
- **声望商店**：用声望购买永久加成：DPS 提升、点击力提升、起始金币、冷却缩减
- **3 种挑战模式**：
  - ☮ 和平主义 — 禁手动点击（x1.5 声望）
  - ⏱ 极速挑战 — 30 分钟达到青铜时代（x2.0 声望）
  - ✋ 纯手工 — 禁用 DPS 装备（x2.5 声望）

### 装备协同（原有系统保留）
- **乘数联动**：noob_training → noob_clicker（2^n）
- **协同效应**：orcish_pride 激活 goblin × gremlin
- **力量联动**：noob_gremlin → gremlin → noob_clicker
- **全局乘数**：cps_multiplier（1.01^n）、click_booster（2^n）

## 项目结构

```

├── main.py              # 入口，组合根
├── config.py            # 从 JSON 加载全部配置

├── ui.py                # 渲染层（纪元条/标签/技能栏/商店）

├── README.md
├── requirements.txt
└── .gitignore
```

### 架构

```
main.py  (组合根)
  ├── engine.py  (纯逻辑层)
  │     ├── UpgradeDef     — 装备定义（category/era/requires）
  │     ├── GameState      — 可序列化状态（含声望/挑战）

```

## 技术要点

- **零外部依赖**：tkinter + json + dataclasses
- **数据驱动**：所有内容（装备/纪元/技能/挑战/声望）在 `game_data.json` 中定义
- **存档兼容**：加载旧存档自动补齐新字段
- **超大数字**：内置格式化器支持超过 10^308 的数字
